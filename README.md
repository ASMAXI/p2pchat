
 # Drift

[![GitHub release (latest by date)](https://img.shields.io/github/v/release/ASMAXI/p2pchat)](https://github.com/ASMAXI/p2pchat/releases/latest)


Drift — голосовой чат без «облака»

Обычные приложения (Steam Chat, Discord и т.п.) гонят голос через свои сервера: ты → их сервер → друг. Даже если вы в одной комнате / одной сети.

Drift работает иначе — P2P.
Голос идёт напрямую между вами: ты → друг. Сервер посередине не слушает и не хранит разговор.

А если у кого-то «кривой» интернет / серый IP / жёсткий NAT?
Тогда соединение само выравнивается через VPS — как запасной мост, чтобы вы всё равно услышали друг друга. Это не «всё всегда через сервер», а помощь только когда прямой путь не получается.

Что важно:

комнаты и переписка живут у вас локально, не в чужой базе;
нет привычки «всё через датацентр» — поэтому нагрузка и трафик обычно меньше, чем у классических голосовых приложений;
для друзей — ссылка-приглашение, зашли и говорите.
Короче: по возможности — напрямую, по необходимости — через VPS, без лишней серверной каши.


Создатель — **ASMAXI**.

## Как пользоваться

1. Установите Drift с страницы Releases.
2. Укажите имя и создайте комнату (или войдите по ссылке друга).
3. Дождитесь туннеля и отправьте приглашение друзьям.
