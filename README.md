 # Drift

[![GitHub release (latest by date)](https://img.shields.io/github/v/release/ASMAXI/p2pchat)](https://github.com/ASMAXI/p2pchat/releases/latest)


Приватный мессенджер для друзей: чат, голос и демонстрация экрана.

Создатель — **ASMAXI**.

## Скачать

Установщики Windows — на странице релизов:

**https://github.com/ASMAXI/p2pchat/releases**

В приложении: **Настройки → Проверить обновления**.

## Как пользоваться

1. Установите Drift с страницы Releases.
2. Укажите имя и создайте комнату (или войдите по ссылке друга).
3. Дождитесь туннеля и отправьте приглашение друзьям.

Подробности и советы — в разделе About последнего релиза / в приложении (Диагностика, Настройки).

Репозиторий исходников закрыт. Здесь публикуются только сборки для установки и автообновления.
