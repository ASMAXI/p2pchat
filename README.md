# Drift

**Drift** — приватный групповой мессенджер без постоянного облачного сервера. Хост ни за кем не закреплён: роль координатора «дрейфует» между участниками. Комната живёт, пока онлайн хотя бы один desktop с доступным адресом.

Создатель — **ASMAXI**. Текущая версия — **0.10.0**.

## Релиз и обновления

1. Поднять версию в `artifacts/p2pchat/src-tauri/tauri.conf.json` и `Cargo.toml`.
2. `git tag v0.10.0 && git push origin v0.10.0` — Actions соберёт NSIS `.exe` + `.msi` и опубликует GitHub Release.
3. В приложении: Настройки → **Проверить обновления** → **Обновить до X** — Drift скачает установщик, запустит его в пассивном режиме, закроется и перезапустится уже новой версией.

## Архитектура

```
Текст + signaling  →  control plane (локальный hub + авто Cloudflare Quick Tunnel)
Голос              →  mesh WebRTC + встроенный free TURN (свой TURN — позже / Pro)
```

Друзьям **не нужны** ngrok-аккаунт и ручной Metered: desktop сам скачивает `cloudflared` и поднимает туннель; TURN по умолчанию — Open Relay.

### Временные логи (тест)

В приложении: **Диагностика** → блок «Временные логи» → **Копировать** или **Скачать .txt**.  
Каждый участник после проверки присылает свой файл — там туннель, session, ICE/голос (без текста чата).

### Desktop UX (0.2)

- Крестик окна **сворачивает в трей**; полный выход: ПКМ по иконке → **Выход**
- Диагностика/Настройки из комнаты — оверлеи (голос не сбрасывается)
- Громкость микрофона и громкость каждого участника — локально (как в Discord)
- Шумоподавление / эхоподавление — переключатели в голосовой карточке
- Настройки → **Проверить обновления** → установка в один клик (с 0.3.0; текущий релиз **0.10.0**)
- Голосовой канал → **Поделиться экраном** (тот же WebRTC mesh, video-трек + renegotiation)

## Удаление (Windows)

NSIS-деинсталлятор при полном удалении (не при обновлении) чистит только данные Drift:
`%AppData%\com.p2pchat.desktop`, `%LocalAppData%\com.p2pchat.desktop`, кэш `%TEMP%\drift-update`, автозапуск и схемы `drift://` / `p2pchat://`. Чужие папки не трогает.

## Запуск для друзей (desktop)

1. Установить сборку Windows (Actions → installer).
2. Создать комнату — подождать авто-туннель (первый раз скачает cloudflared).
3. Скопировать приглашение другу — https на `asmaxi.github.io/p2pchat/join/` (кликабельна в Steam) → «Открыть Drift».
   Лендинг деплоится workflow `Deploy invite landing` (Settings → Pages → Source: GitHub Actions).
4. У друга должно быть указано имя — без него войти нельзя.
5. Голос: войти в голосовой канал (для разных сетей нужен живой TURN / Metered).

Если туннель не поднялся — Настройки → «Поднять / обновить туннель».

## Разработка

```bash
pnpm install
pnpm run test
cd artifacts/p2pchat && pnpm desktop:dev
```

Опционально стабильный TURN (нужен для голоса между разными сетями):

1. Бесплатный аккаунт на [metered.ca](https://www.metered.ca/) → API key  
2. В приложении: Настройки → Расширенные → Metered API key  
   или в `.env` при сборке:

```env
# artifacts/p2pchat/.env
VITE_METERED_API_KEY=...
VITE_METERED_APP_NAME=yourapp
```

Свой VPS/coturn: Настройки → расширенные → свой TURN (перекрывает Metered).

Статические логины `openrelayproject` больше ненадёжны — без API key или своего TURN голос часто падает между разными Wi‑Fi.
## Last-peer

Пока `online >= 1` и у координатора есть публичный endpoint (авто-туннель), сессия жива. Чтобы интернет-друзья пережили ваш выход, у преемника тоже должен быть desktop с авто-туннелем.
